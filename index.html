Use your own mandolin instead

Record single notes on your instrument and the app will play every melody note with them. Roughly thirty notes is plenty — it pitches the nearest one it has.

1. Record one note at a time, let it ring, trim the silence. Any recorder works; the Voice Memos app is fine.

2. Name each file by its pitch: C4.mp3, D4.mp3, E4.mp3 … Middle C is C4, so the mandolin's open courses are G3, D4, A4, E5.

3. Put them in a folder called samples/mandolin/ next to index.html in your repository.

4. Add a file called samples/manifest.json listing them:

5. Upload the whole samples folder to GitHub with Add file → Upload files, then reload the app with Shift-⌘-R.

The same works for guitar, bass, cello and fiddle — add a block per instrument. Anything you do not supply falls back to the recorded soundfont, and then to synthesis offline.
